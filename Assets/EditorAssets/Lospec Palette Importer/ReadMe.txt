1. Go to Tools
2. Click Lospec Palette
3. Go to Lospec.com
4. Find a palette you lick
5. Copy the URL and paste into the URL section of the Lospec Importer Window
6. If you want the color palette to be saved to unity palettes click create color palette.
	If you want to create a "LospecPaletteObject" scriptable object click "Create Scriptable Object"
7. Once you are done Press Create Palette
